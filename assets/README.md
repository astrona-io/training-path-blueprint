# Path Assets

This directory contains static, path-level assets.

## Allowed Assets
* Cover images or banners (like `cover.png` or `thumbnail.jpg`)
* Path badges or completion certificate graphics
* High-level diagrams illustrating the entire progression of this path

## Prohibited Assets
* Reading materials, slides, or PDFs
* Lab configurations, setup scripts, or solutions
* Inline images for exercises and quizzes

All instructional, reading, and lab-related assets must reside directly in their respective **ATS (Astrona Training Specification)** repositories.
